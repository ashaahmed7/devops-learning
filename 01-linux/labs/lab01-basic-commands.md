Dealing with spaces in folder names - use `\`between words or `“ ”` .

e.g. `mkdir My\ Project\ 2` or `“My Project 2”`

`./` means **"the current directory".** It's commonly used to run a program or script that's in the folder you're currently in.

e.g. `./set_permissions.sh` will print the script that’s inside ‘Permissions changed for example.txt’
