# Terminal Commands

## Key Concepts

There are many useful commands in Linux!

## Common Commands

`pwd` stands for **Print Working Directory**. It shows the **current folder (directory)** you're in within the terminal.

`ls` stands for **list**. It shows the files and folders in your current directory.

`ls -a` list all files, including hidden ones.

`ls -l` lists files and directories in the current directory using the **long format**, which shows detailed information about each item.

`ls -R` lists files and directories **recursively**.

- `ls` = list files and folders
- `-R` = recursive, meaning it also shows the contents of all subdirectories

`touch` is a command used to **create an empty file** or **update a file's timestamp**.

`mkdir` stands for **make directory**. It creates a new folder.

`rmdir` stands for **remove directory**. It deletes an empty folder.

`rm` stands for **remove**. It is used to delete files (and, with options, folders).

`rm -r` is used to **remove (delete) a directory and everything inside it**.

`cd` stands for **change directory**. It lets you move between folders in the terminal.

`cd ..` is a command used in the command line (such as Terminal, Command Prompt, or a shell) to **move up one directory level**.

`mv` is used to **move** files/directories to another location or **rename** files/directories.

`cp` copies files or directories.

`echo` is a command that **prints text or variables to the terminal**.

`cat` stands for **concatenate**, but most people use it to **display the contents of a file**.

`grep` stands for **Global Regular Expression Print**. It is used to **search for text within files or command output**.

`>` is the **output redirection** operator. It takes the output of a command and writes it to a file. e.g.

`echo "Hello" > file.txt`

`<` is used for **input redirection**. It takes the contents of a file and sends them as input to a command. e.g. `cat < example.txt`

`>>` is the **append redirection** operator. It **adds output to the end of a file** without deleting what's already there.

`2>` redirects **standard error (stderr)** to a file.

`&>` means **redirect both standard output (stdout) and standard error (stderr) to the same file**.

`chsh` stands for **change shell**. It lets you change your **default login shell** (for example, from Bash to Zsh).

`head` shows the **first 10 lines** of a file by default.

`tail` shows the **last 10 lines** of a file by default.
